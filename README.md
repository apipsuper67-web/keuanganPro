# 📱 KonterPro - Landing Page Aplikasi Kasir & Stok Counter HP UMKM

> **Solusi Kasir Digital, Scan IMEI Otomatis, Manajemen Multi-Varian Stok, dan Laporan Laba/Rugi Real-Time khusus UMKM Counter HP di Indonesia.**

---

## 🌟 Fitur Utama Landing Page
- **Hero & Live POS Mockup**: Visualisasi antarmuka aplikasi kasir lengkap dengan animasi laser scanner IMEI dan status omzet harian.
- **Problem & Solution**: Komparasi interaktif masalah konter konvensional vs solusi digital KonterPro.
- **Feature Showcase**: 4 pilar utama (Pencatatan IMEI & Garansi, POS & Cetak Thermal/WA, Manajemen Stok Multi-Varian, Laporan Laba Bersih).
- **Interactive POS & IMEI Simulator**: Pengunjung dapat mencoba memilih unit HP, simulasi scan IMEI, memilih metode bayar (QRIS/Tunai/Transfer), dan melihat live preview **Struk Thermal 58mm** serta **E-Nota WhatsApp**.
- **Kalkulator Hemat Waktu & ROI**: Simulasi estimasi waktu rekap dan pencegahan kebocoran stok berdasarkan volume penjualan.
- **Paket Harga**: Switch interaktif bulanan & tahunan (diskon 25%).
- **Formulir Registrasi Trial**: Pendaftaran uji coba 14 hari full akses tanpa kartu kredit.
- **FAQ Accordion & Login Modal**: Pertanyaan umum seputar printer thermal Bluetooth, mode offline, dan keamanan data.

## 🚀 Cara Menjalankan Secara Lokal

1. **Clone repository:**
   ```bash
   git clone https://github.com/apipsuper67-web/appsforUMKM.git
   cd appsforUMKM
   ```

2. **Jalankan Server Lokal (Node.js):**
   ```bash
   node server.js
   ```

3. **Buka di Browser:**
   Kunjungi [http://localhost:3000](http://localhost:3000)
